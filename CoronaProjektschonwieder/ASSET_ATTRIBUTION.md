# Asset Attribution (Lemmings-inspired 3D build)

## Summary
- Runtime scene geometry, materials, and HUD visuals are procedural or authored in-project.
- No proprietary Lemmings assets, logos, or copyrighted level files are included.

## Third-party components
- `three` / `@react-three/fiber` / `@react-three/drei` are used for rendering and controls.
- License family: MIT (as declared by package maintainers on npm).

## Asset policy
- Gameplay is inspired by classic lemmings-style mechanics only.
- Visual identity, level layout, and naming are project-specific.
- This repository intentionally avoids importing copyrighted original franchise assets.
